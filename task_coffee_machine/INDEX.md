## Quick Execution Commands

### 1. Run the Main Application
To run the interactive Coffee Machine program in your terminal:
```bash
python3 task_coffee_machine/main.py
```

### 2. Run the Test Suite
To execute all automated unit and E2E tests:
```bash
python3 -m unittest task_coffee_machine/test_main.py
```
